# 🔵 Scenario 3: Custom User Breach Scenario Template

## 1. Scenario Definition
* **Dam Facility**: Mettur Dam (Stanley Reservoir)
* **User Parameters**: Reservoir Starting Level (ft), Breach Width (m), Breach Formation Time (min), Breach Bottom Elevation (m MSL).
* **Purpose**: Allows emergency managers to evaluate sensitivity of downstream arrival time to custom breach geometries.
